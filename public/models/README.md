# NASA 3D Models Directory

Place Draco-compressed `.glb` models here for automatic loading:

- `opportunity-draco.glb` (NASA Opportunity Rover)
- `apollo-draco.glb` (NASA Apollo 11 Lunar Module)
- `voyager-draco.glb` (NASA Voyager Spacecraft)

Free models are available directly from NASA's official 3D Resources portal:
https://nasa3d.arc.nasa.gov/
